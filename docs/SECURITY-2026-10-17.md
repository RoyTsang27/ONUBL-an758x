# CVE review — 17 October 2026

Reviewed baseline: main commit a0c8ee0615d94d4fe407d607cee2cf8496e41d0c, based on U-Boot v2026.10. This review checks the latest public U-Boot notices and the boot/network dependencies used by the twelve AN758x targets. A distribution notice published after a release does not by itself mean the release lacks the fix; the vulnerable code and configuration were checked.

## Changes in this patch

| CVE / component | Finding and action |
| --- | --- |
| CVE-2026-71972 — BMP RLE8 | The source still lacked upstream framebuffer bounds checks. Backport commit 5201e83342d64c2f438ea35158575f28225e752e, checking both encoded and absolute runs and propagating decoder errors. VIDEO is disabled on the twelve shipped targets, so this is a source fix for optional builds rather than a reachable network flaw on these devices. |
| CVE-2026-34878 — TF-A FIP metadata | The vendor TF-A parser trusted 64-bit ToC offsets/sizes and did not reject short successful reads. Backport the upstream bounds/short-read protection while retaining the vendor encryption-flag accessor and UBI boot backend. Query the backing extent, bound each ToC read, validate before narrowing to AArch32 sizes, bound incremental payload reads and clear failed-open state. Valid FIP contents, flags and storage layout remain compatible. |
| Mbed TLS security baseline | TF-A used the obsolete external 3.4.1 dependency. CI now downloads the official 3.6.7 LTS release archive and verifies its published SHA-256. The supported build script rejects older or unknown versions and unsupported major versions. Adapt the TF-A source list to 3.6, including its new bignum/curve files. Later 3.6.x security releases remain allowed. |

Mbed TLS 3.6.7 includes fixes for CVE-2026-49300, CVE-2026-50579, CVE-2026-50583, CVE-2026-50580, CVE-2026-35336 and other issues listed in its release notes. This dependency update includes their upstream fixes; it does not imply every advisory's TLS, PSA or private-key-operation prerequisites were enabled in the AN758x firmware.

## Configuration limits

The twelve unchanged configurations do not enable VIDEO, Android bootmeth, NFS download, wget, ext4, SquashFS or U-Boot's MBEDTLS_LIB. Their Web Recovery server remains enabled and uses the existing lwIP HTTP server; it is separate from the wget HTTP client.

The unused vendored U-Boot Mbed TLS 3.6.0 tree is not upgraded by this patch. Enabling MBEDTLS_LIB or TLS in a custom configuration requires updating that separate library and validating its TLS/certificate policy. The external Mbed TLS 3.6.7 dependency updated here is the one compiled into TF-A.

lwIP CVE-2026-91018 requires a 6LoWPAN interface; CVE-2026-87121 requires the MQTT application; CVE-2026-8836 requires SNMPv3. These components are not built/enabled by lib/lwip/Makefile and the AN758x lwipopts.h. Their unused sources are not claimed to be patched. TF-A CVE-2026-34879 requires the BL1 FWU SMC interface, which is not part of the supported BL21/BL22/BL23 build flow.

## Compatibility and validation

The patch retains full manual/physical recovery, restricted automatic recovery, signing policy, unsigned development builds and the existing persistent BL2/FIP layout. It does not add mandatory FIT signatures or anti-rollback.

CI runs test/airoha/cve_regressions.py with AddressSanitizer and UndefinedBehaviorSanitizer against extracted, unchanged parser function bodies from the actual patched sources. It covers valid and malformed FIP metadata, 64-bit wrap/truncation candidates, short reads, failure cleanup, encryption flags, incremental reads and EOF. BMP tests cover encoded/absolute runs, EOL/DELTA cursor underflow, upper bounds and valid drawing at 8/16/24/32 bpp. The dependency guard is checked with accepted, obsolete, unknown and unsupported versions.

Existing UBI compatibility and Web/TFTP boot-storage preservation tests also run. Every supported device is built through the normal preloader/FIP packaging pipeline. Actual cold boot, NAND recovery and OpenWrt/ImmortalWrt sysupgrade checks still require physical hardware.

The source artifact contains ONUBL-CVE-2026-10-17.patch against the reviewed baseline and security-replacement-files/ with repository-relative paths, alongside the complete source ZIP and full v2026.10 patch. The manifest records the baseline and SHA-256 digests.
